# بوابة جودة المحتوى — خط الأساس

تشغيل: `python scripts/quality_gate.py path/to/metadata.json`

تقبل البوابة بيانات JSON. مثال مبدئي لقناة الأطفال:

```json
{
  "channel": "children",
  "title": "ماذا يعني الصدق؟",
  "script": "ضع هنا النص الكامل للفيديو العربي بعد مراجعته وتأكد أن طوله مناسب.",
  "video_path": "output/final.mp4",
  "religious_references": [{"name": "مرجع موثوق", "note": "يُراجع بشريًا قبل النشر"}],
  "child_safety_review": true,
  "rights_review": true,
  "editorial_review": true
}
```

لقناة الأخبار، أضف `sources` على شكل قائمة من عناصر تتضمن `url` بروابط HTTPS إلى نطاقين مستقلين على الأقل. يجب التحقق من استقلال المصادر وحداثتها ومضمونها بشريًا أو بأداة تحقق منفصلة؛ البوابة الحالية تتحقق من وجود نطاقين فقط ولا تثبت صحة الخبر.

هذه البوابة حارس أولي حتمي وليست حكمًا دينيًا أو نظامًا كاملًا لكشف كل أشكال الضرر. مراجعة بشرية مطلوبة قبل النشر، وخاصة للأطفال والموضوعات الدينية والأخبار العاجلة. لا تُفعّل النشر العام حتى ينجح اختبار التوليد والمراجعة ورفع فيديو تجريبي خاص.
