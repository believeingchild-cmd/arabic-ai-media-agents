# أول فيديو عربي: تشغيل ومراجعة

هذا الدليل خاص بالتجربة الأولى. لا يفعّل النشر العام؛ الإعداد الافتراضي متوقف (`paused=true`) ووضع الموافقة يدوي.

## متطلبات جهاز Linux
- Python 3.10+
- Ollama يعمل محليًا مع النموذج `llama3.2:3b` أو نموذج متوافق مثبت
- FFmpeg وFFprobe على PATH
- حزم `requirements.txt` مثبتة في بيئة افتراضية
- اتصال إنترنت لتوليد الصور والصوت

## الإعداد
```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
ollama pull llama3.2:3b
ffmpeg -version
ffprobe -version
```

تأكد أن Ollama يعمل، ثم من جذر المستودع نفّذ أول فيديو يدويًا:
```bash
python scripts/make_video.py "مهنة الطبيب: كيف يساعد الناس؟" --scenes 4
```

ينشئ السكربت مجلدًا تحت `out/job_...` ويكتب السجل في قاعدة بيانات المشروع. ابحث عن الملف النهائي داخل مجلد المهمة وافحصه بصريًا وسمعيًا قبل أي رفع.

## ما الذي يجب مراجعته؟
1. هل الصوت عربي واضح والنطق مناسب؟
2. هل الترجمة العربية مقروءة واتجاهها وتشكيل الحروف صحيحان؟
3. هل الصور مناسبة للأطفال ولا تتضمن نصوصًا مشوهة أو مشاهد مخيفة؟
4. راجع أي ادعاء ديني مقابل مرجع موثوق؛ لا تنشر إن لم تستطع التحقق.
5. افحص حقوق الصور والموسيقى ومصادرها.
6. اختبر رفعًا خاصًا/مسودة أولًا؛ لا تجعل الفيديو عامًا في هذه المرحلة.

## قيود معروفة
- إعداد القناتين منفصل في ملفات JSON، لكن ربط كل إعداد بمسار توليد ونشر مستقل ما زال يحتاج تكاملًا برمجيًا.
- بوابة الجودة الحالية أداة أولية مستقلة وليست مربوطة بعد مباشرةً بكل مسار النشر؛ لا تعتبرها حماية مفعّلة حتى يتم دمجها في `autopilot.py` و`publish.py`.
- TikTok/Instagram يتطلبان إعدادات API وصلاحيات فعلية؛ وجود ملف الإعداد لا يمنح هذه الصلاحيات.
- اختبارات الوحدة أضيفت لكن لم يتم تشغيلها في بيئة تنفيذ هذا التعديل.
## فتح بوابة المراجعة بعد إنتاج الفيديو
سيُنشأ ملف `quality_gate.json` بجوار الفيديو. النشر محظور افتراضيًا حتى تُراجع الملف وتعدّل علامات المراجعة يدويًا:
- اجعل `editorial_review` و`rights_review` بالقيمة `true) بعد التحقق.
- لقناة الأطفال: اجعل `child_safety_review` بالقيمة `true) وأضف مرجعًا دينيًا موثوقًا إلى `religious_references` عند وجود محتوى ديني.
- للقناة العامة: أضف رابطين HTTPS على الأقل من نطاقين مستقلين داخل `sources` بعد التحقق من الخبر.
- لا تعدّل `video_path` إلا إذا نقلت الملف النهائي فعلًا.

إذا فشلت البوابة، سيوقف `publish.py` النشر ويعرض أسباب الرفض. هذه الفحوصات آلية أولية ولا تغني عن حكم المراجع البشري.
